# Hessa Albinali Portfolio

The website uses a single Luxury Editorial theme throughout, with one reusable case-study template.

## Preview
Open index.html in a browser, or activate GitHub Pages under Settings → Pages → Deploy from branch → main / root.

## Adding projects
1. Upload original images to assets/.
2. Append one object in projects.js with a unique slug, title, type, summary, concept, and images.
3. Commit. The new project shows on the homepage and gets its own project.html?slug=... page.

## Current status
Core website files have been committed. Original imagery still needs to be uploaded; image paths are explicitly marked in assets/README.md. This does not yet provide a visual admin dashboard or automatic image uploads. GitHub Pages activation, if needed, is separate.
